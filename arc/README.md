# SkyStrat Arc GIS Plugin

To use these tools, you will need to locate `BuskMethod.pyt` for the Busk method algorithm for calculating and mapping stratigraphic height, and `ThreePointProblemToolbox.pyt` for the three-point problem method for calculating strike and dip from three points and a digital elevation model. 

First, download these or unzip the release, whichever you prefer. Place these files into a folder that you plan to locate from within ArcCatalog inside ArcGIS Pro. Then, navigate to these files in ArcCatalog, right click, and click `Add To Project`. Now, whichever `.pyt` file you have added to the project should appear in the Geoprocessing/Tools pane, under the Toolboxes heading at the top. They should also be findable by search in the Geoprocessing/Tools pane. Clicking the title next to the script icon should open the window for inputs and running each tool. 

Use the guide and the demonstration videos in the main folder for guidance on use of the tools.
